# 1.3 变更与验收

- 将前台、后台和 API 的源码分别按入口、组装、业务模块与共享职责组织。
- 前后台共用的客户端、会话、评论、Markdown、反馈和基础样式集中到 `apps/shared/`。
- 管理后台文章审核、评论审核分别迁入模块目录。API 校验及通用错误移到 API 共享层。
- 沸点调整排序区、发布区、动态卡片及侧栏的布局。提交审核、话题、签到和互动沿用现有数据流。
- 项目入口、路由和 API 保留原路径。无需新增 PostgreSQL 迁移。更新历史文档中的源码链接，保留原有业务说明。
