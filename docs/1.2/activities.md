# 社区活动设计 v1.2

社区活动由管理员维护，公开首页和创作者中心按展示时间读取活动卡片。本模块保存标题、摘要、封面和跳转地址，并通过发布状态、展示区间和排序控制出现时机。本文记录 2026 年 11 月 25 日的实现，供产品、开发和测试共同维护。

## 页面与职责

| 页面或区域 | 职责 |
| --- | --- |
| 公开首页右栏 | 展示当前可见活动，封面、标题、摘要和可选外链 |
| `/creator` 的创作活动 | 从同一公开接口读取，展示前 3 条活动 |
| `/admin/activities` | 列表、创建时间筛选、分页和新建入口 |
| `/admin/activities/new` | 输入内容与展示设置，预览卡片并保存 |
| `/admin/activities/:id` | 编辑既有活动，携带版本更新 |

活动外链使用新标签打开并带 `rel="noreferrer"`。没有外链时标题显示为普通文本。公开封面加载失败会隐藏图片，后台预览显示封面失败或地址格式反馈。相关调用见 [首页活动区域](../../apps/web/features/articles/articles.tsx)、[创作者活动区域](../../apps/web/features/creator/creator.tsx)和[后台活动页](../../apps/admin/features/activities/activities.tsx)。

## 数据模型

| 字段 | 类型与规则 |
| --- | --- |
| `id` | UUID 主键 |
| `editor_id` | 用户外键，记录最后一次保存的管理员 |
| `title` | `varchar(120)`，必填，去掉首尾空白后仍需有内容 |
| `summary` | `varchar(300)`，必填，去掉首尾空白后仍需有内容 |
| `url` | 可空跳转地址，API 上限 1000 字符，允许 HTTP 或 HTTPS，拒绝携带用户名或密码 |
| `cover_url` | 可空图片地址，API 上限 2000 字符，要求 HTTPS，拒绝携带用户名或密码 |
| `status` | `DRAFT`、`PUBLISHED`、`UNLISTED`，默认草稿 |
| `sort_order` | 0 到 9999，越小越靠前，默认 0 |
| `visible_from` | 可空开始时间，包含该时间点 |
| `visible_to` | 可空结束时间，不包含该时间点 |
| `version` | 正整数，默认 1，每次更新递增 |
| `created_at`、`updated_at` | 带时区时间戳，精度为毫秒 |

数据库提供 `activities(status, sort_order, id)` 索引。CHECK 约束保护标题和摘要非空、版本为正、顺序范围，以及结束时间晚于开始时间。封面地址由后续迁移加入。URL 协议和长度校验由 API 执行。[Prisma 模型](../../prisma/schema.prisma) · [活动初始迁移](../../prisma/migrations/202611250005_activities/migration.sql) · [封面迁移](../../prisma/migrations/202611250007_activity_cover/migration.sql)

## 可见性和状态

| 状态或时间条件 | 公开表现 |
| --- | --- |
| `DRAFT` | 不进入公开活动接口 |
| `PUBLISHED` 且开始时间未到 | 不进入公开活动接口 |
| `PUBLISHED` 且在展示区间内 | 进入候选列表 |
| `PUBLISHED` 且结束时间已到 | 不进入公开活动接口 |
| `UNLISTED` | 不进入公开活动接口 |

开始或结束为空时，对应一端没有时间限制。两端都有值时要求 `visibleFrom < visibleTo`。公开查询使用服务端当前时间，按 `sortOrder` 升序、ID 升序返回最多 5 条。后台列表可以查看全部状态。状态通过保存活动表单设置，已下架活动可重新保存为已发布，实际显示仍受时间区间约束。

活动没有单独的审核状态。每次保存记录最后配置人和版本，当前模型没有活动操作历史表。查询与状态规则见 [活动 API](../../apps/api/features/activities/activities.ts)。

## API 和权限

| 方法与接口 | 参数 | 结果 |
| --- | --- | --- |
| `GET /api/activities` | 无 | 当前可见卡片数组，最多 5 条 |
| `GET /api/admin/activities` | `page`，可选 `from`、`to` | `{items, hasMore}`，每页 30 条 |
| `GET /api/admin/activities/:id` | UUID | 活动编辑数据和版本 |
| `POST /api/admin/activities` | 活动内容及展示设置 | 201，返回新活动 |
| `PATCH /api/admin/activities/:id` | 活动内容、展示设置及当前 `version` | 返回更新结果和新版本 |

公开响应只包含 `id`、`title`、`summary`、`url` 和 `coverUrl`。后台响应增加状态、顺序、展示时间、版本和更新时间，列表同时返回创建时间。

后台读取要求 ADMIN，会话缺失返回 401，普通用户返回 403。写入还经过来源和 CSRF 校验。请求只接受 Schema 声明字段，管理员身份由服务端会话确定。

创建必须提交标题、摘要、跳转地址或 null、状态、顺序及两个展示时间或 null。`coverUrl` 可省略。更新同样使用整表单参数并携带版本，省略 `coverUrl` 会保留原封面，传 null 或空白内容清空封面。[活动 API](../../apps/api/features/activities/activities.ts)

## 日期筛选与时区

后台列表的 `from`、`to` 按活动创建日期筛选，与活动的展示时间字段分别计算。参数采用 `YYYY-MM-DD`。日期筛选以北京时间零点为起点，结束日期包含当天，并转换成下一天北京时间零点的排他上界。

前台编辑器的展示时间输入采用浏览器本地时间，提交前转为 ISO 时间点。重新加载时再转回本地输入格式。创建日期筛选中的无效日期、起止倒置返回 400。[日期筛选转换](../../apps/api/shared/admin-date-range.ts)

## 后台编辑交互

表单左侧组织基本内容和展示设置，右侧预览活动卡片。标题和摘要随输入更新。封面输入延迟 350 毫秒更新预览，HTTPS 地址可尝试加载，非法地址、未配置和图片失败各有对应反馈。状态选择同时更新预览状态文案。

保存期间禁用提交按钮。首次保存成功后替换为该活动的编辑地址，后续保存使用返回的新版本。保存成功显示反馈，并刷新后台活动列表缓存。

当另一位管理员先保存后，旧版本提交返回 409。当前输入保留，页面提供「放弃当前修改并加载最新版本」操作。主动加载最新版本会重建表单，使用服务端的新内容和版本。

## 错误与恢复

| 场景 | API 或界面反馈 | 持久化结果 |
| --- | --- | --- |
| 标题或摘要为空白 | 400 字段校验错误 | 无写入 |
| 结束时间早于或等于开始 | 400 `INVALID_ACTIVITY_WINDOW` | 无写入 |
| 跳转地址协议不符或含凭据 | 400 `INVALID_ACTIVITY_URL` | 无写入 |
| 封面使用 HTTP 或含凭据 | 400 `INVALID_ACTIVITY_COVER` | 无写入 |
| 编辑 ID 不存在 | 404 | 无写入 |
| 版本已过期 | 409 `STATE_CONFLICT` | 保留数据库中已确认版本 |
| 网络失败 | 显示错误，可重试 | 以服务端是否完成为准，重试需核对版本 |

公开活动卡片的封面加载失败不改变活动记录。当前后台保存只失效后台列表缓存，已打开的首页或创作者活动区在重新查询前可能继续显示缓存内容。

## 验收基线

1. 游客可读取公开活动，匿名后台请求返回 401，普通用户后台读写返回 403，缺少 CSRF 的写入返回 403。
2. 创建草稿后公开接口不可见，改为已发布且展示时间有效后可见，下架后消失。
3. 对同一活动使用两个旧版本同时编辑，只有符合当前版本的更新成功，失败方输入仍在。
4. 无开始或结束限制、未来开始、已经结束和精确结束时间点均符合左闭右开区间规则。
5. 多条活动按顺序值和 ID 稳定排序，公开最多 5 条，后台每页 30 条。
6. 只有有效 HTTPS 封面可通过保存校验。预览能区分未配置、非法地址和图片加载失败。
7. 后台创建日期的北京时间边界、非法日期、起止倒置与活动展示时间互不混用。
8. 手机宽度下表单、卡片预览和保存反馈可阅读，状态控件能通过键盘操作。

上述场景在现有接口测试和浏览器脚本中有对应实现。测试源码可复现校验条件，执行结果应随每次交付记录。[活动接口测试](../../tests/activities.integration.test.ts) · [日期测试](../../tests/admin-dates.integration.test.ts) · [浏览器脚本](../../scripts/browser-activities.mjs)
