# 沸点页面布局 1.3

沸点继续使用 `/pulses` 列表、`/pulses/:id` 详情与 `/pulses/leaderboard` 排行榜。业务接口和权限见 [沸点模块 1.2](../1.2/pulses.md)。

## 阅读和发布

| 区域 | 内容与操作 |
| --- | --- |
| 左栏 | 社区排行榜入口、全部沸点和话题筛选。话题请求失败时提供重试。 |
| 主栏 | 顶部独立显示推荐、最新和关注。发布区提供正文、字符数、话题及可选 HTTPS 图片地址。下方内容流按条展示作者、时间、正文及可用互动。 |
| 右栏 | 账号入口、我的沸点、我的关注、每日签到、精选沸点和推荐话题。精选列表从标题进入详情。游客看到登录入口。 |

正文最多 2000 字符，图片最多 4 张。内容与图片均为空时禁止提交。提交期间锁定输入，失败保留草稿，成功提示等待审核。创作者中心可查看近期沸点。

## 响应式行为

桌面用三栏组织，优先分配阅读宽度给主栏。较窄窗口将辅助卡片移至主栏下方。手机上主内容采用单栏，话题横向滚动，排序和输入仍处于内容流上方。按下键盘 Tab 时应能定位话题、排序、正文输入和发布操作，选中态可从当前按压状态及标签识别。

## 验收

- 切换推荐、最新和关注，选中状态与实际列表一致。话题筛选和排行榜入口可用。
- 编辑正文和图片时计数变化，选择话题后可提交审核。空表单不可提交。
- 沸点卡片保留关注、点赞、评论和详情交互。
- 桌面栏目按内容分区，375px 窄屏无横向页面溢出。

实现见 [沸点前台](../../apps/web/features/pulses/pulses.tsx)与[沸点样式](../../apps/web/features/pulses/pulses.css)。
