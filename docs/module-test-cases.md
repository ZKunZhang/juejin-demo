# 模块测试用例

版本 v0.3，均未执行。使用独立 PostgreSQL 和浏览器上下文。测试从空库应用迁移，通过种子提供初始管理员和普通用户。验证注册用例时另建独立账号。每个测试组恢复独立夹具。

## 工具

| 层级 | 工具与核验 |
| --- | --- |
| 单元与组件 | Vitest、React Testing Library，检验参数边界、表单反馈、Markdown 和目录。 |
| API 与数据库 | Fastify inject、Vitest、Docker Compose PostgreSQL、psql。以 HTTP 响应和独立 SQL 结果为断言。 |
| 浏览器 | Playwright，为游客、管理员和各普通用户分别建立浏览器上下文，覆盖角色、持久化与跨用户可见性。 |

## M1 登录注册

| ID | 操作 | 预期 |
| --- | --- | --- |
| M1-01 | 注册正常账号、刷新、退出并用旧 Cookie 请求 me，最后重登 | 注册 201，刷新保留身份，退出后旧会话 401，重登成功。 |
| M1-02 | 并发注册同一用户名及大小写变体 | 一次成功，冲突返回 409，仅一条用户记录。 |
| M1-03 | 提交非法用户名、过短密码、未知字段和 role=ADMIN | 400，无注册及会话写入。用正常注册重试只获得 USER。 |
| M1-04 | 错误密码、未知账号、过期会话、停用用户 | 均不可获得有效会话。错误凭据响应一致。 |
| M1-05 | 检查注册与登录响应、Cookie、用户及会话库记录 | JSON 无密钥字段。密码为 Argon2id 哈希，会话存令牌摘要，Cookie 为 HttpOnly。 |
| M1-06 | 用错误 Origin 或缺失 CSRF token 提交写请求；短时反复登录 | 来源无效的写请求被拒绝，登录触发限频，无非法状态变更。 |
| M1-07 | 重启 API 后以未过期会话访问；在另一浏览器登录并退出原会话 | 重启后有效会话可用，退出仅撤销当前会话。 |

## M2 文章发布与阅读

| ID | 操作 | 预期 |
| --- | --- | --- |
| M2-01 | 作者创建 Markdown 草稿并选两个标签，刷新；游客查列表和详情 | 作者可读原文；游客列表无该草稿，详情 404；两个关联准确。 |
| M2-02 | 在隔离环境直接发布；游客从列表进入详情 | 状态和时间持久化，过滤及排序正确。Markdown、代码块、表格和重名中文标题锚点正确。 |
| M2-03 | 替换标签；提交重复 ID、不存在 ID、超限内容；模拟事务失败 | 正常替换准确。非法或失败请求不会部分写入。 |
| M2-04 | 另一用户伪造 authorId 或提交旧 version；渲染含原始 HTML 及危险 URL 的文章 | 不允许越权。旧版本 409。危险内容不执行，安全内容可读。 |
| M2-05 | 用标签与游标翻页，切换筛选；在生产配置请求临时发布路由 | 不重复或漏掉固定数据集中的文章。跨筛选游标拒绝。生产路由不可用。 |

## M3 审核与评论管理

| ID | 操作 | 预期 |
| --- | --- | --- |
| M3-01 | 作者提交，游客查询，管理员审核通过，再由游客打开 | 待审时不可公开读取。审核后变为 PUBLISHED，列表和详情可读，只有一条对应审核日志。 |
| M3-02 | 缺原因驳回，再正常驳回、修改并重提；尝试编辑待审版本 | 缺原因 400。原因向作者可见，修改重提成功；待审不可编辑。 |
| M3-03 | 额外创建一个测试管理员，两名管理员并发处理同一版本；模拟日志写失败 | 仅一项成功，另一个返回 409。日志写失败时状态回滚。 |
| M3-04 | 管理员下架，作者转草稿并重提 | 下架后游客详情 404，作者仍可访问，历史操作保留。 |
| M3-05 | 普通用户进入后台并直调管理接口；管理员会话失效后再次操作 | 普通用户 403，失效会话 401，无状态或日志变更。 |
| M3-06 | 管理员隐藏、恢复种子评论，重复发送旧预期状态 | 管理列表状态和持久化结果一致，每次成功仅一条日志，旧状态返回 409。 |

## M4 多用户互动

| ID | 操作 | 预期 |
| --- | --- | --- |
| M4-01 | reader_beta、reader_gamma 评论同一公开文章，管理员隐藏其一 | 两条评论作者不同，游客仅看见仍可见的评论。下架后评论不可公开读取。 |
| M4-02 | 两人分别点赞，Beta 重复激活并取消 | 独立关系各一行，重复不加计数，取消只移除 Beta 关系。 |
| M4-03 | 两人分别收藏同文，各自读取收藏后取消；下架文章再查 | 列表按会话隔离，取消只影响本人，下架内容被过滤。 |
| M4-04 | Beta、Gamma 关注作者，Beta 重复关注后取消并尝试自关注 | 粉丝关系彼此独立。重复不增加，自关注失败且无数据写入。 |
| M4-05 | 匿名写互动，伪造 userId，向草稿或下架文章新增互动 | 未授权请求被拒绝。目标不可见时无新增。已有点赞或收藏可取消。 |
| M4-06 | 重启 API 并重新登录多个账号，再比对记录和前台状态 | 评论、关注、点赞和收藏均持续可读，状态和归属一致。 |
