# 1.2 变更与验收

## 从 1.1 到 1.2

| 模块 | 1.2 补充内容 |
| --- | --- |
| 架构和权限 | 按现行 React 前台、管理后台、Fastify、Prisma 和 PostgreSQL 描述入口、会话边界和迁移流程。 |
| 文章和沸点 | 明确公开、待审、驳回、下架与恢复流程。管理员可以恢复已下架沸点，恢复操作与审核记录一同提交，保留原互动且不重复通知。 |
| 评论 | 记录文章、沸点两级评论和章节评论。迁移 020 防止数据库直写产生跨内容、自引用或三级回复，同时保护既有归属关系。 |
| 课程 | `/courses/` 直接进入所选或默认课程的公开章节，章节列表、正文和评论连在同一阅读流程。课程无公开章节时进入介绍页。 |
| 互动和个人页 | 补充收藏合集的归属、默认收藏、分页、双账号隔离与关注同步。显式映射收藏的现有索引名，兼容现有数据库。个人关注、收藏和文章互动状态返回私有缓存策略。 |
| 创作与运营 | 补充创作者中心、个人沸点状态、独立管理入口、评论审核、活动以及站内通知和排行榜的实际流程。 |
| 文档 | 原有设计、评审及测试资料保存为 1.1 快照，1.2 采用独立 Markdown 模块和总索引。 |

## 已执行验证

| 验证 | 结果 |
| --- | --- |
| Prisma | 在既有测试库升级，在空库从初始版本运行全部 20 项迁移。本地开发库同步迁移后，Prisma 结构差异检查未发现差异。 |
| 数据完整性 | PostgreSQL 直写验证跨内容、三级、自引用及归属变更被拒绝，正常评论和审核更新可用。文章评论限制删除与沸点回复级联删除原规则均经过验证。 |
| 并发与失败 | 两个数据库连接同时插入回复和尝试非法修改父级，已提交回复保留正确归属。模拟含历史异常数据的迁移，确认失败后事务回滚。 |
| 自动化 | 10 个测试文件共 13 项通过。包含管理员恢复沸点、重复操作冲突、通知去重规则及个人接口响应头。类型检查和构建通过。 |
| Chrome | 独立测试库验证后台恢复沸点后公开可读且审核日志落库。课程验证目录、章节切换、评论提交、刷新与隔离。5173 与 5175 另检查了课程直达和新后台接口。 |

## 当前设计边界

- 文章评论的最热排序范围为最近 100 条一级评论。沸点详情采用服务端排序及分页。
- 课程评论为单层。课程评论管理、收藏合集重命名与删除、课程进度和独立媒体资产管理属于后续设计。
- 生产部署、备份周期及恢复演练需要按真实运行配置另行验证。
