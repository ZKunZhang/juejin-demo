# 开发者社区首期验收用例

v0.1，待评审。当前均为未执行用例。使用独立测试库和上传目录，准备游客、普通账号 A、B 和编辑账号 C。A 关注 B。预置同标签和跨标签文章、图片沸点、公开及草稿小册、活动和精选。写入用例使用独立夹具或执行后恢复。

P0 为发布前必过。P1 为相关体验与边界。

| 编号 | 优先级 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| NAV-01 | P0 | 游客依次打开首页、沸点、课程、文章详情和个人页 | 全站导航可用。首页左侧标签、中间内容、右侧活动可见。游客看到登录和注册。 |
| NAV-02 | P1 | 打开活动、APP、AI 用量、作品广场、创作者中心 | 活动可读。范围待定的入口显示状态。创作者中心发布要求登录。 |
| AUTH-01 | P0 | 注册新账号并刷新；退出后复用旧会话，再重新登录 | 刷新保留登录。旧会话失效，重新登录可访问自己的资料。 |
| AUTH-02 | P0 | 注册同名、大小写变体、过短密码；用错误密码登录 | 请求被拒绝，同名只保留一条用户记录，失败不生成会话。 |
| AUTH-03 | P0 | 游客直调写接口；A 伪造 B 的 ID 修改资料、发布或编辑精选 | 游客返回 401。普通用户无权修改 B 的资料和编辑资源。发布作者由会话确定。 |
| HOME-01 | P0 | 切换标签及推荐、最新、关注；搜索关键字并切换内容类型 | 标签、类型、关键字按当前视图共同生效。关注仅显示已关注作者。 |
| HOME-02 | P1 | 搜索无结果，访问不存在的内容，模拟网络失败 | 各自显示空态、404 和可恢复错误。表单失败后可重试。 |
| ART-01 | P0 | 发布含同名标题、列表、代码、链接和图片的 Markdown | 持久化后正确渲染。目录保留层级且同名标题可分别定位。 |
| ART-02 | P0 | 提交含脚本、事件属性和危险链接的 Markdown、评论或个人网站 | 不执行脚本或危险跳转。安全内容仍能读取。 |
| ART-03 | P0 | 游客跳到评论区；A 发布有效、空白及超长评论 | 有效评论可刷新读取，无效请求无写入。 |
| ART-04 | P0 | 并发重复点赞再取消；收藏到指定收藏集再移除 | 点赞只增减一次，收藏集归属和条目与数据库一致。 |
| ART-05 | P1 | 复制分享链接并打开；查看作者、相关推荐和精选 | 链接可访问，作者可进入个人页，同标签推荐排除当前文，空精选收起。 |
| ART-06 | P1 | 同一会话并发打开，再于 30 分钟内和窗口后打开；另一会话打开 | 首次、窗口后及另一会话分别计一次。窗口内重复不计。 |
| PULSE-01 | P0 | 发布纯文字、纯图片及四图加文字；刷新和重启 | 内容和图片顺序稳定，重启后可读取。 |
| PULSE-02 | P0 | 发布空沸点、五张图、超限图、伪造图片；模拟写盘失败 | 拒绝无效输入。无可见半成品、孤立关联或不可回收的临时文件。 |
| PULSE-03 | P1 | 切换关注、推荐、最新与话题，再取关 B | 关注流随关系变化；推荐与最新遵循排序口径。话题过滤持续有效。 |
| PULSE-04 | P0 | 并发重复签到，并跨北京时间午夜再签到 | 当天只新增一行，两次请求均可确认已签到；次日可再新增。 |
| PULSE-05 | P1 | 编辑上架和撤下精选沸点 | 右栏同步变化，撤下精选后仍可从公开沸点列表访问原文。 |
| COURSE-01 | P0 | 联合选择分类和难度，复制地址并重新访问，重置筛选 | 条件共同生效，地址可复现筛选，重置可访问全量公开课程。 |
| COURSE-02 | P0 | 切换介绍、目录，打开第二章和草稿章节地址 | 章节按配置排序，同类推荐优先且排除本册，游客无法读取草稿。 |
| USER-01 | P0 | A 修改昵称、头像、简介、网址；B 刷新访问；再提交非法 URL 和图片 | 公开资料一致，无效数据被拒绝且原资料可读。 |
| USER-02 | P0 | 逐一打开个人页七个标签；B 直接请求 A 的收藏、点赞记录 | 各标签按类型展示，跨用户访问不返回私有明细。 |
| USER-03 | P1 | B 点赞 A 的文章和沸点，打开文章并关注、取关 A；A 尝试自关注 | 获赞只计文章。阅读和双方关注统计一致，自关注被拒绝。 |
| USER-04 | P0 | A 创建并重命名专栏和收藏集，将自己的文章加入专栏，再将 B 的文章加入收藏集。B 尝试修改 A 的资源，A 尝试把 B 的文章加入自己的专栏 | 所有者可管理专栏及收藏集。公开文章可收藏。跨用户管理和跨作者入栏被拒绝，原关联仍可读。 |
| MEDIA-01 | P0 | A 提交 B 尚未发布的图片 ID，分别尝试绑定为头像和沸点附件；再尝试绑定自己的临时文件 | 拒绝绑定他人或仍处于暂存状态的图片，无新增关联。原头像保持可读。 |
| DB-01 | P0 | 创建帖子、图片、评论、点赞、会话后重启；同时检查页面和数据库 | 已提交记录与文件持续可读，未过期会话继续有效。 |
| DB-02 | P0 | 模拟事务中途失败、重复关联和无效外键 | 失败回滚，无孤儿记录。签到、点赞、收藏和关注仍唯一。 |
| UI-01 | P1 | 在 390px 和 1440px 检查布局，并用键盘操作导航及表单 | 无横向溢出，焦点可见，控件可识别，错误文本可读取。 |

话题订阅、付费课程、APP 下载、AI 用量和作品发布在范围确认后补充用例。执行时记录浏览器截图、接口响应和数据库查询结果。图片尺寸上限、密码长度和编辑维护方式等断言随评审定稿。
